# learn-ecommerce-metrics-with-phoebe

Every ecommerce number, explained on one store. A two-track interactive course by Phoebe Fu -
part of the [Learn with Phoebe](https://phoebefu6.github.io/learn-with-phoebe/) hub and
course 1 of the ecommerce & growth analytics series.

- **Leader track (a1-a6)** - reading mode: the GMV equation, the metric dictionary, the funnel,
  the weekly business review, honest benchmarks, and metric governance. No computation.
- **Analyst track (b1-b8)** - computing mode: one running store (Mango Lane, a mobile-first
  fashion app: 240K visitors, 360K sessions, 9,720 orders, $660,960 GMV) decomposed completely,
  with a live driver-tree simulator - edit any lever (PDP penetration, add-to-cart, checkout
  completion, AOV) and GMV recomputes; simulate a drop and trace the coral trail to the cause.

Static HTML/CSS/JS, no build step, runs entirely in the browser.

Built from the GA4 ecommerce documentation (purchase journey, checkout journey, sessions and
users), Shopify's analytics reports, Baymard Institute cart-abandonment research, and
IRP Commerce / Dynamic Yield / Littledata benchmarks.

by Phoebe Fu
